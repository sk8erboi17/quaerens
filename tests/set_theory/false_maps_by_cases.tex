$\mathbb{N} = \{1, 2, 3, \ldots\}$, $\mathbb{N}_{0} = \mathbb{N} \cup \{0\}$. Each statement is a true one about a map defined by cases, changed a little: a case condition moved, a coefficient changed, a property swapped, cases that overlap with different values, cases that leave a point out, a value outside the codomain. Items 17--21 have values in pairs, items 22 and 23 compare a variable over a set of pairs with a pair written out, items 24--28 are about the iterates $f^{n}$, items 29--34 are maps from $\mathbb{R}$, items 35--39 have parameters, the last seven are maps from $\mathbb{C}$.
