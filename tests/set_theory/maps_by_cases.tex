$\mathbb{N} = \{1, 2, 3, \ldots\}$, $\mathbb{N}_{0} = \mathbb{N} \cup \{0\}$. Each map is defined by cases (on a remainder, on an order, on a point, on being an integer, on a parameter), or with an absolute value, which is a definition by cases. Items 13--17 have values in pairs: $(a, b) = (c, d)$ means $a = c$ and $b = d$. Items 18 and 19 compare a variable over a set of pairs with a pair written out. The last three are about the iterates $f^{n}$, defined by $f^{1} = f$ and $f^{n + 1} = f \circ f^{n}$.
