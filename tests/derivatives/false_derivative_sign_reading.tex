\title{False derivatives that are true as algebra}

\maketitle
Each statement is false as a statement about a derivative, and true if $\frac{d}{dx}$ is read as the fraction of the letters $d$ and $x$, that is $\frac{1}{x}$. None of them may be proved.

\begin{enumerate}
\item $\displaystyle \frac{d}{dx} 5 = \frac{5}{x}$
\item $\displaystyle \frac{d}{dx} x^{2} = x$
\item $\displaystyle \frac{d}{dx}\left( x^{2} \right) = \frac{x^{2}}{x}$
\item $\textstyle \frac{d}{dx} x^{3} = x^{2}$
\item $\displaystyle \dfrac{d}{dx}\left( x^{4} \right) = x^{3}$
\item $\displaystyle x^{2} + \frac{d}{dx} x^{2} = x^{2} + x$
\item $\displaystyle 2 \cdot \frac{d}{dx}\left( x^{2} \right) = 2x$
\item $\displaystyle \frac{d^{2}}{dx^{2}} x^{3} = \frac{x^{3}}{x^{2}}$
\end{enumerate}
