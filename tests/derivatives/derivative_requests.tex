Each item asks for a derivative of a fixed order, with nothing after it: the engine answers with the derivative, written in a readable form, which it reads back and checks. The answer holds where the function and the formula are defined.

\begin{enumerate}
\item $\displaystyle \frac{d}{dx}\left( x^{2} \tan x \right)$
\item $\displaystyle \frac{d}{dx}\left( \arcsin x \right)$
\item $\displaystyle \frac{d^{2}}{dx^{2}}\left( x^{3} - 2x \right)$
\item $\displaystyle \frac{d}{dx}\left( e^{x} \sin x \right)$
\item $\displaystyle \frac{d}{dx}\left( \ln|x| \right)$
\item $\displaystyle \frac{d}{dx}\left( |x - 1| \right)$
\item $\displaystyle \frac{d}{dx}\left( x^{x} \right)$
\item $\displaystyle \frac{d}{dx}\left( \sqrt{x^{2} + 1} \right)$
\item $\displaystyle \frac{d}{dx}\left( \frac{x + 1}{x - 1} \right)$
\item $\displaystyle \frac{d}{dx}\left( \sqrt[3]{x} \right)$
\item $\displaystyle \frac{d}{dx}\left( \arccot\frac{1}{x} \right)$
\item $\displaystyle \frac{d^{3}}{dx^{3}}\left( \log_{2} x \right)$
\end{enumerate}
