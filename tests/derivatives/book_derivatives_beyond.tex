\maketitle
Every statement below is true: the printed result of an exercise collection, confirmed by an independent check. The engine does not prove them yet, because the printed form needs identities that its exact algebra does not apply; it must never call them false.

\begin{enumerate}
\item $\displaystyle \frac{d}{dx}\left( \arcsin\sqrt{1 - 2x} \right) = -\frac{1}{\sqrt{2x(1 - 2x)}}$
\item $\displaystyle \frac{d}{dx}\left( \arccos\sin x \right) = -\frac{\cos x}{|\cos x|}$
\item $\displaystyle \frac{d}{dx}\left( \sqrt{\frac{1 + \cos x}{1 - \cos x}} \right) = \frac{\sin x}{|\sin x|} \cdot \frac{1}{\cos x - 1}$
\end{enumerate}
