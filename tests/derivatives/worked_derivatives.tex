Each item asks for a derivative. The engine must also record how it is found: the derivative of each piece of the expression, from the innermost outwards, with the rule that gives it. The expected lines are in \texttt{test\_worked\_derivatives.c}.

\begin{enumerate}
\item $\displaystyle \frac{d}{dx}\left( x^{2} \tan x \right)$
\item $\displaystyle \frac{d}{dx}\left( \frac{x^{2} - 3}{x + 2} \right)$
\item $\displaystyle \frac{d}{dx}\left( \sin(3x) \right)$
\item $\displaystyle \frac{d}{dx}\left( e^{x} \sin x \right)$
\item $\displaystyle \frac{d}{dx}\left( \sqrt{x^{2} + 1} \right)$
\item $\displaystyle \frac{d}{dx}\left( (2x + 1)^{3} \right)$
\end{enumerate}
