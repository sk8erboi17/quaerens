\maketitle
This note explains what the test data in \texttt{false\_parameter\_discussions.tex} is used for. That file is input for the engine in \texttt{main.c}; it is read by the test \texttt{test\_parameter\_discussions.c} in this folder.

\begin{enumerate}
\item \textbf{Purpose.} The file holds 30 false statements about a rank or a system of linear equations with a real parameter. They are anti-regression data: the engine must declare each of them false, with certificates that the independent checker accepts, and must never prove one.

\item \textbf{How they were made.} Each is a statement of \texttt{parameter\_discussions.tex} (the sources are listed in \texttt{parameter\_discussions\_about.tex}) with its result changed by little, in one of the ways in which a discussion written by hand goes wrong:
\begin{itemize}
\item a special value of the parameter forgotten (statements 1, 28, 30), moved (2, 8, 10, 12, 16, 20, 27), or added (4, 7, 9, 13, 17): statement 4 adds $t = 0$ and statement 5 puts $t = -\frac{1}{3}$, the two values for which, as the book warns, only one of the two bordered minors vanishes;
\item a rank wrong by one (3, 6), and a rank that is never reached (11);
\item a case of the discussion forgotten, so that a formula is claimed where the solutions are others (14, 22, 23) or where it is not defined (19, 29);
\item one component of a solution changed, or its sign (15, 18, 21, 24, 25, 26).
\end{itemize}

\item \textbf{A third computation.} Every statement was recomputed by the independent oracle \texttt{tools/fuzz/fuzz\_linear\_algebra.py parameter-data}, which decides each fact for every value of the parameter with ranks taken from minors: it found all 30 false.

\item \textbf{What is being tested.} That a wrong discussion is refuted with a value of the parameter, not merely left unproved: the condition on the parameter that replaces each fact is exact, so the statement that remains is false at a definite value, which the sign table finds. And that every certificate of a generic case is no longer accepted when its claim is reversed, a number of its statement is changed, a witness is removed, or its entry \texttt{where} is replaced by ``for every value''.

\item \textbf{Format expected by the test.} The same as \texttt{parameter\_discussions.tex}.

\item \textbf{How to run it.} From the top folder of the repository:
\begin{verbatim}
cc -std=c11 -O2 -Wall -Wextra -Werror -o /tmp/test_parameter_discussions \
    tests/linear_algebra/test_parameter_discussions.c && /tmp/test_parameter_discussions
\end{verbatim}

\item \textbf{Expected result.} The line \texttt{PASS: 30 of 30 statements \dots{} are declared false with certificates that the checker accepts one by one \dots{} and no longer accepts when one of a generic case is altered}.
\end{enumerate}
