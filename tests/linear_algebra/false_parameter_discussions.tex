Every statement below is false. Each is a statement of \texttt{parameter\_discussions.tex} with its result changed by little: a rank wrong by one; a special value of the parameter moved, forgotten or added; a case of the discussion forgotten, so that a formula is claimed where it does not hold or is not defined; one component of a solution changed. The engine must declare each of them false, not merely fail to prove it. Every statement was recomputed by an independent oracle with exact fractions (\texttt{tools/fuzz/fuzz\_linear\_algebra.py parameter-data}). The sources are listed in \texttt{false\_parameter\_discussions\_about.tex}.
