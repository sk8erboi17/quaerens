Each item is an expression without a relation: a request to compute it, as in ``compute the inverse'', ``compute the determinant'', ``compute the rank''. The engine must answer RISOLTO with the value, which is the result printed in the collection of exercises. The expected answers are in \texttt{test\_linear\_algebra.c}; the sources are listed in \texttt{book\_matrices\_about.tex}.
