Every statement below is true. Each says that a product, a determinant, a rank, an inverse or a similar quantity of matrices written in full has the value printed as its result in a collection of exercises of a first course in linear algebra, or is a concrete instance of a result printed there. Every value was recomputed by an independent oracle with exact fractions (\texttt{tools/fuzz/fuzz\_linear\_algebra.py data}). The sources are listed in \texttt{book\_matrices\_about.tex}.
