Every statement below is true. Each says that a condition with exponentials or logarithms of the real variable $x$ holds exactly for the values printed as its result in a school textbook (corrected in the one exercise where the printed result is wrong, as an independent check found). A domain of a function is written as the condition that the function equals itself, which holds exactly where it has a value. A comparison counts as false where one of its sides has no value. The engine must prove them all.
