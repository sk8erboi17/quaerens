\maketitle
This note explains what the test data in \texttt{false\_log\_of\_negative\_sine\_or\_cosine.tex} is used for. That file is input for the engine in \texttt{main.c}; it is read by the test \texttt{test\_logs\_trig\_powers\_roots\_inductions.c} in this folder.

\begin{enumerate}
\item \textbf{Purpose.} The file holds 12 statements with the logarithm of a sine or cosine that is not positive. It is an anti-regression test: the engine must never report any of them as proved.

\item \textbf{What makes them hard.} The engine computes sines and cosines as complex exponentials and logarithms as $\ln|u|$, so its algebra sees two equal sides, and the value of $\cos 2$ is not a number it can compare with zero. It decides the sign from the quadrant of the angle. A wrong table of signs, an angle taken in the wrong quadrant, or a rule that looks at the general term of a sum and forgets the first ones ($\cos\frac{5}{2^{k}}$ is negative only for $k = 1$) would let one of these statements through.

\item \textbf{Expected result.} The line \texttt{PASS: 12 of 12 false statements rejected}.

\item \textbf{Adding statements.} The argument of the logarithm must be negative or zero for at least one $n \ge 1$, whatever the value of the parameters, by a fact that can be checked by hand.

\item \textbf{How to run it.} From the top folder of the repository:
\begin{verbatim}
cc -std=c11 -O2 -Wall -Wextra -o /tmp/test_logs_trig_powers_roots \
    tests/logs_trig_powers_roots/test_logs_trig_powers_roots_inductions.c \
    && /tmp/test_logs_trig_powers_roots
\end{verbatim}
\end{enumerate}
