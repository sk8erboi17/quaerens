\title{Limits the engine does not decide yet (4)}
\author{}

\begin{document}
\maketitle
Every statement below is true, with the result printed in a collection of exercises and checked by an independent numerical oracle. The engine does not prove them yet; it must never call them false.

\begin{enumerate}
\item $\displaystyle \nexists \lim_{x \to +\infty} \sqrt{x}\cos x$
\item $\displaystyle \lim_{x \to -\infty} (8x + x\sin^{2} x) = -\infty$
\item $\displaystyle \lim_{x \to +\infty} \frac{x^{2} - 5x}{x + 1}\left(e - 2^{\sin x}\right) = +\infty$
\item $\displaystyle \nexists \lim_{x \to +\infty} \frac{x^{2} - 5x}{x + 1}\left(e - e^{\sin x}\right)$
\end{enumerate}
