This note explains what the test data in \texttt{book\_integrals\_beyond.tex} is used for. That file is input for the engine in \texttt{main.c}; it is read by the test \texttt{test\_integrals.c} in this folder.

\begin{enumerate}
\item \textbf{Purpose.} The file holds 8 true statements from the same sources as \texttt{book\_integrals.tex}, with the same changes of notation ($\ln$ for the natural $\log$ of the university sheets, $\arctan$ for $\operatorname{arctg}$). The engine does not decide them yet. It may say so; it must never call one of them false.

\item \textbf{Why they are not decided.}
\begin{itemize}
\item Functions or forms the engine does not handle yet (3 statements): $\arcsin$ of a fraction whose terms have no known sign, $\operatorname{arcosh}$. Two statements of this kind, $\int x \cosh 3x \, dx$ and $\int \frac{dx}{\sqrt{1 + 2x - x^{2}}} = \arcsin \frac{x - 1}{\sqrt{2}} + c$, became provable when $\arcsin$, $\sinh$ and $\cosh$ entered the reader and the rules of differentiation, and moved to \texttt{book\_integrals.tex}.
\item Two statements that were here, $\int \frac{1 + \sqrt{x}}{x(1 + \sqrt[3]{x})} \, dx$ and $\int \frac{dx}{\sqrt{x} + \sqrt[3]{x}}$, went back to \texttt{book\_integrals.tex}. They mix $\sqrt[3]{x}$, the real cube root, defined also for $x < 0$ (rule 11o), with $\sqrt{x}$ and $\sqrt[6]{x}$: $\sqrt[3]{x} = (\sqrt[6]{x})^{2}$ holds only where $x \ge 0$. The zero test now uses the domain, where both sides are defined, and there $x \ge 0$ (rules 11q and 12d of \texttt{main.c}).
\item Two improper integrals whose antiderivative the engine does not find, $\int_{0}^{2} \frac{dx}{\sqrt{4 - x^{2}}}$ and $\int_{0}^{1} \frac{x^{2}}{\sqrt{1 - x^{2}}} \, dx$ (an arcsine): the comparison of rule 30l shows that they converge, but not their value.
\item $\int_{0}^{1} \frac{dx}{e^{\sqrt{x}} - 1} \in \mathbb{R}$: the comparison would decide it, but the sign table cannot show that $e^{\sqrt{x}} - 1$ does not vanish on $(0, 1)$, so the continuity of the integrand on the open interval is not established. $\int_{0}^{\infty} \cos x \, dx \notin \mathbb{R}$: the partial integrals $\sin R$ oscillate; the engine has no rule for an oscillation, and says it does not know.
\item $\int_{e}^{e^{3/2}} \ldots$: exact algebra does not know that $\ln e = 1$, and the integrand has a square root that vanishes at the lower bound.
\end{itemize}
Ten statements left this file with the improper integrals (rules 30k and 30l): nine went to \texttt{improper\_integrals.tex}, and $\int_{-1}^{0} \sqrt[5]{x} \, dx$ to \texttt{book\_integrals.tex}.

\item \textbf{Expected result.} The line \texttt{PASS: none of the 8 true statements \ldots{} is called false}, with the number of those proved. When one becomes provable it should move to \texttt{book\_integrals.tex}, or to \texttt{improper\_integrals.tex} if it is improper.

\item \textbf{How to run it.} From the top folder of the repository:
\begin{verbatim}
cc -std=c11 -O2 -Wall -Wextra -o /tmp/test_integrals \
    tests/integrals/test_integrals.c && /tmp/test_integrals
\end{verbatim}
\end{enumerate}
