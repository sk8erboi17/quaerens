Every statement below is true, with the meaning the engine gives to an antiderivative: on every open interval where both sides are defined, the derivative of the right side is the integrand. They fix where the differential $dx$ may stand, which logarithm $\ln$ is, and what a definite integral with reversed bounds is. The engine must prove them all.

\begin{enumerate}
\item $\displaystyle \int \frac{1}{x} \, dx = \ln|x| + c$
\item $\displaystyle \int \frac{1}{x} \, dx = \ln x + c$
\item $\displaystyle \int \frac{1}{x} \, dx = \ln(-x) + c$
\item $\displaystyle \int \frac{1}{x} \, dx = \ln\left|3x\right| + C$
\item $\displaystyle \int 2x \, dx = x^{2} + 5 + k$
\item $\displaystyle \int \frac{dx}{x^{2} + 1} = \arctan x + c$
\item $\displaystyle \int x^{2} + 1 \, dx = \frac{x^{3}}{3} + x + c$
\item $\displaystyle \int \frac{x \, dx}{x^{2} + 1} = \frac{1}{2}\ln\left(x^{2} + 1\right) + c$
\item $\displaystyle \int \sin 2x \, dx = -\frac{1}{2}\cos 2x + c$
\item $\displaystyle \int \frac{dt}{t^{2} - 1} = \frac{1}{2}\ln\left|\frac{t - 1}{t + 1}\right| + c$
\item $\displaystyle \int 0 \, dx = c$
\item $\displaystyle \int_{0}^{1} x^{2} \, dx = \frac{1}{3}$
\item $\displaystyle \int_{1}^{0} x^{2} \, dx = -\frac{1}{3}$
\item $\displaystyle \int^{\pi}_{0} \sin x \, dx = 2$
\item $\displaystyle \int_{0}^{1} \frac{dx}{x^{2} + 1} = \frac{\pi}{4}$
\item $\displaystyle \int_{1}^{e} \frac{1}{x} \, dx = \ln e$
\end{enumerate}
