\maketitle
This note explains what the test data in \texttt{integral\_requests.tex} is used for. That file is input for the engine in \texttt{main.c}; it is read by the test \texttt{test\_integrals.c} in this folder.

\begin{enumerate}
\item \textbf{Purpose.} The file holds 80 requests: the integrals of \texttt{book\_integrals.tex} and \texttt{book\_integrals\_beyond.tex} without their results, $\int f \, dx$ or $\int_{a}^{b} f \, dx$. The engine must find the result itself; the answer is a verdict RISOLTO with $F + c$, or with the value.

\item \textbf{What it exercises.} The search for an antiderivative (rules 30c to 30h), and the check of what it writes: the answer is read back by the reader of the program and verified like a stated result (30a, 30b, 30i). The textbook results are in the table \texttt{expected[]} of \texttt{test\_integrals.c}, as data. The test rewrites each answer as a statement, $\int f \, dx = F + c$, which the engine must prove; then compares it with the textbook: $\int 0 \, dx = F - F_{\mathrm{book}} + c$ must be proved (the two antiderivatives differ by a constant on every interval), and for a definite integral $\int_{0}^{1} 0 \, dx = V - V_{\mathrm{book}}$ (the two values are equal). The comparison is skipped where the textbook result uses a function the engine does not know ($\arcsin$, $\sinh$, $\operatorname{arcosh}$) or is $+\infty$.

\item \textbf{The answers need not look like the book's.} The engine integrates $\sin^{3} x \cos^{4} x$ by writing it as a sum of cosines of multiple angles, $-\frac{3}{64}\cos x - \frac{1}{64}\cos 3x + \frac{1}{320}\cos 5x + \frac{1}{448}\cos 7x$, while the book has $\frac{1}{7}\cos^{7} x - \frac{1}{5}\cos^{5} x$; the two differ by a constant, and the test checks exactly that.

\item \textbf{Expected result.} The line \texttt{PASS: 59 of 80 requests \ldots{} answered (at least 59 wanted)}. The other 21 are the integrals of the statements the engine does not decide (improper integrals, a fifth root of negative numbers, $\ln e$), and eight whose antiderivative it does not find: seven square roots of quadratics, which need the substitutions of Euler or the trigonometric and hyperbolic ones, and $x^{3}\sqrt{2 - x^{2}}$.

\item \textbf{How to run it.} From the top folder of the repository:
\begin{verbatim}
cc -std=c11 -O2 -Wall -Wextra -o /tmp/test_integrals \
    tests/integrals/test_integrals.c && /tmp/test_integrals
\end{verbatim}
\end{enumerate}
