The first 52 are the results of the textbook exercises 215--233 altered by little, three for each exercise: a case of the parameter dropped, or answered wrongly, a $<$ for a $\le$, the sign of an endpoint changed, the two roots not swapped where the parameter changes sign (of exercises 224 and 226 only the alteration that drops the absolute value is here). The others were written by hand, each with a refuting pair of values in mind; some fail only at one value of the parameter, and one only at an irrational one. The last is a mistake really made while writing these tests: the engine found it.
