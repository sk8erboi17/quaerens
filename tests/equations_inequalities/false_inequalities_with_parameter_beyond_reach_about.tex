\maketitle
This note explains what the test data in \texttt{false\_inequalities\_with\_parameter\_beyond\_reach.tex} is used for. That file is input for the engine in \texttt{main.c}; it is read by the test \texttt{test\_equations\_inequalities.c} in this folder.

\begin{enumerate}
\item \textbf{Purpose.} The file holds 13 false statements in two or three real variables that rule 18t does not treat. None of them may ever be proved: when the rule is extended, they must become refuted, never proved.

\item \textbf{What it exercises.} The border of the rule. A statement outside it must get the answer that it is not treated, not an answer computed as if the part that is not understood were not there.

\item \textbf{Variety.} The altered results of exercises 224 and 226 (with $\left|2a - 1\right|$ and $\sqrt{4 - k^{2}}$ beside $x$), $\left|x\right|$, $\sqrt{x^{2} + a^{2}}$, $2^{x}$ and $\sin x$ with a parameter, three real letters, a rational parameter, and $x^{3} + ax + 1$, whose discriminant vanishes at a cube root.

\item \textbf{Expected result.} The line \texttt{PASS: 13 of 13 false statements rejected}.

\item \textbf{How to run it.} From the top folder of the repository:
\begin{verbatim}
cc -std=c11 -O2 -Wall -Wextra -o /tmp/test_equations_inequalities \
    tests/equations_inequalities/test_equations_inequalities.c \
    && /tmp/test_equations_inequalities
\end{verbatim}
\end{enumerate}
