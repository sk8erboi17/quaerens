Every statement below is false. The first 18 were written by hand, each with one value of $x$ in mind that refutes it: an endpoint counted that is not a solution, a point where a side has no value, an isolated solution forgotten, an irrational number. The others come from the fuzz script \texttt{tools/fuzz/fuzz\_reals.py}: a true statement with one endpoint moved, opened or closed, or one piece dropped, and the independent oracle confirmed that it is false.
